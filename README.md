# MultiAI
MultiAI is an app that lets you run AI models on your phone using LLaMa C++ (llama.cpp) Instead of LiteRM, which crashes on some models, llama.cpp supports all models natively.
[Download Latest](https://github.com/Trey16885/MultiAI/raw/refs/heads/main/MultiAI-v3.5.apk)
_Note: Models may crash a phone, as they use RAM, CPU, NPU, VRAM, and GPU. Depending on your RAM, it determines which model you can use._
